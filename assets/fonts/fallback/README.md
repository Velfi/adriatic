# Bundled Unicode fallback fonts

These product-owned fallback faces make Adriatic text output deterministic
across supported platforms. They are static Noto releases distributed under
the SIL Open Font License in `OFL.txt`; they are not supplied by
`zelda-engine`.

The configured chain covers Arabic, Hebrew, Armenian, Georgian, Ethiopic,
Devanagari, Bengali, Gurmukhi, Gujarati, Odia, Tamil, Telugu, Kannada,
Malayalam, Sinhala, Thai, Lao, and monochrome symbols/emoji. The primary Noto
Sans/Serif faces cover Latin, Greek, and Cyrillic.

`NotoEmoji-Regular.ttf` is the regular-weight monochrome Noto Emoji face from
Google Fonts. CJK, vertical writing, and color emoji are intentionally
unsupported.
