## In-editor placement

Use the `GREEK ASSETS` tool (`G`) in the Adriatic terrain editor. Choose an asset in the inspector, click terrain to place it, use the mouse wheel to rotate the preview, use `Shift` + wheel to scale it, and press `Backspace` to remove the selected placement.
